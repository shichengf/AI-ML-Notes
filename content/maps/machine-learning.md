# 机器学习学习路线

## 1. 数学基础

- 线性代数：向量、矩阵、特征值与矩阵分解
- 概率统计：随机变量、常见分布、估计与假设检验
- 微积分与优化：梯度、链式法则、凸优化

## 2. 经典机器学习

- 监督学习：回归、分类、模型评估
- 无监督学习：聚类、降维、表示学习
- 泛化：偏差与方差、正则化、交叉验证

## 3. 深度学习

- 神经网络与反向传播
- 优化器、归一化与正则化
- CNN、Transformer 与生成模型

## 4. AI 工程

- 数据处理与实验管理
- 模型部署、监控与 MLOps
- 可靠性、安全性与评估
