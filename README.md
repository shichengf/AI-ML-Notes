# AI-ML-Notes

这是 <https://shichengf.github.io/AI-ML-Notes/> 的公开网站仓库。

网站使用 [Quartz v5](https://github.com/jackyzha0/quartz) 构建，并通过 GitHub Pages 自动发布。公开内容由私有 Obsidian 知识库筛选导出；请不要直接在本仓库的 `content/` 中长期维护笔记。

网站支持中英双语。英文内容使用 `en/` 路径，页面顶部可以切换语言。

## 本地预览

```powershell
npm install
npx quartz build --serve
```
